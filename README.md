# Решала

Интерактивный сайт-концепция бота: анимированный персонаж, демо-чат, четыре сценария и таймер фокуса. Белый фон, чёрные тексты и красные акценты.

HTML, CSS и JavaScript без сборки. Для локального запуска: `python3 -m http.server 8080`.

Чат использует локальные шаблонные ответы, внешняя нейросеть не подключена. Переписка не передаётся на сервер.

GitHub Actions публикует сайт в GitHub Pages при пуше в `main`. Если Pages ещё не включён, выберите Settings → Pages → Source → GitHub Actions.
