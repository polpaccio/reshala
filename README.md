# Omnibot

Белый робот-помощник по пользовательскому референсу. Светлый монохромный сайт: около 70% белого, 20% серого и 10% чёрных акцентов.

Сохранены: слежение глаз и головы за курсором, демо-чат и четыре сценария, доска дел с локальным сохранением, выбор главного дела, генератор первого шага, таймер 5/15/25 минут, дыхательная пауза, меню для телефона, звук, эффекты нажатий, анимации появления и переключатель уменьшения движения.

Демо-чат использует локальные шаблоны; внешняя нейросеть не подключена. Дела хранятся только в localStorage браузера, старый ключ сохранён для совместимости.

HTML/CSS/JavaScript без сборки. Локально: `python3 -m http.server 4173`. GitHub Pages публикуется автоматически из `main`.

Бесплатный лимит — 3 добавленные задачи за всё время в данном браузере. После третьей показывается диалог со ссылкой https://t.me/tyughjvbnfbot; до перехода новые задачи не добавляются. Переход открывает лимит до 30 задач и сохраняет доступ локально. Подтверждение через API самого Telegram-бота не используется. Существующие задачи при обновлении сохраняются.

Прокрутка чата передаётся странице на границах списка сообщений; элементы сообщений не сжимаются. Анимации карточек учитывают уменьшение движения.

В верхней панели — профиль Telegram: вход через официальное окно `oauth.telegram.org`, имя, фото, username, ссылка на профиль и выход. В `telegram-config.json` находится только публичный botId. В BotFather командой `/setdomain` нужно разрешить `polpaccio.github.io`. Токен бота и Client Secret сайту не нужны и не должны попадать в репозиторий.

Профиль передаёт подписанный ответ Telegram на сервер бота. `/website/profile` проверяет HMAC-SHA256, срок до 24 часов, Telegram ID и точный Origin сайта, затем возвращает только статус Plus, срок, скидку и доступность поддержки из общей базы бота. Секреты хранятся на сервере. Старым сессиям без подписи потребуется выйти и войти заново. Покупки и промокоды оформляются в Telegram; после возврата статус обновляется.

Верхняя навигация: «Подписка», «Техподдержка», «Задачи», «Демо-чат». Подтверждённый Plus открывает локальную доску до 30 задач; при выходе/истечении/ошибке проверки платный доступ не сохраняется. Сами записи сайта пока не синхронизируются с задачами бота.

Форма поддержки использует `/website/support`: запрос идемпотентен по request_id, история изолирована по проверенному Telegram ID. Текст новых обращений с сайта и ответы сохраняются в таблице support_site_messages общей базы, удаляются каскадно вместе с аккаунтом. В группе есть метки «Источник: Сайт», «Бот», «Mini App». Ответ владельца группы сохраняется для сайта независимо от доставки его копии в чат с ботом; сайт проверяет ответы каждые 20 секунд при открытом разделе. Вложения ответов доступны в Telegram, на сайте показывается подпись или уведомление о вложении. История до обновления не восстанавливается из Telegram. Публичная ссылка группы указана пользователем.

Серверная часть интеграции находится в проекте бота: app/website.py, подключение в app/miniapp.py; app/support.py и app/storage.py сохраняют историю ответов. Для разработки проверяются подпись/возраст входа, CORS, изоляция обращений, статусы подписки и сохранение ответов на обоих каналах.

Главная сокращена до робота, Omni Plus и компактного блока Telegram. Категории переключаются по hash без перезагрузки: задачи, фокус, чат, поддержка и «О боте». Существующие функции и адреса разделов сохранены. Все категории видны в шапке: на телефоне — сетка из двух строк. Частички и свечение Plus используют CSS-анимации transform/opacity; при невидимости блока или вкладки приостанавливаются, при уменьшении движения отключаются.

Единый робот из предоставленного аватара используется в логотипах шапки и подвала, заголовке чата и на главном экране. Исходное изображение сохранено без изменения; SVG/CSS показывают голову без подписи. Большой робот сохраняет отслеживание курсора и пиксельное моргание. Блок «Удобнее в Telegram» со ссылкой на бота расположен после содержимого любой категории. Вкладки получили общий светлый фон и контрастное выделение выбранного раздела.
